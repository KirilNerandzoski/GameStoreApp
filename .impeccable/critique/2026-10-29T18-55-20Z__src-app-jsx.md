# Design Critique: IGNIS Omni-Store (Global Universal Shell)

## Design Health Score
Total Score: 23/40 (Rating: Moderate / Needs Refinement)

| # | Heuristic | Score | Key Issue |
|---|-----------|:-----:|-----------|
| 1 | Visibility of System Status | 3 | Cart counts and filter states update cleanly; silent fallback on Supabase sync, no audio status indicator. |
| 2 | Match System / Real World | 2 | Heavy pseudo-military jargon ("Dossiers", "Armory", "Consolidated Payment Protocol") obscures standard e-commerce patterns. |
| 3 | User Control and Freedom | 2 | Modals have close buttons, but synthesized audio cannot be muted, roulette animation cannot be skipped, and XP alert traps focus. |
| 4 | Consistency and Standards | 2 | Inconsistent store counts ("5 storefronts" vs "6 Universes"); red neon overrides department palettes in global components. |
| 5 | Error Prevention | 3 | Steppers prevent negative values, demo autofill prevents form friction; missing inline XP check before triggering crate unbox. |
| 6 | Recognition Rather Than Recall | 3 | Category icons, cover art thumbnails in recent dossiers, and 1-click coupon application reduce memory burden. |
| 7 | Flexibility and Efficiency | 3 | Global Ctrl+K / Cmd+K omni-search, quick-add to cart, and 1-click demo autofill cater well to power users. |
| 8 | Aesthetic and Minimalist Design | 1 | Severe visual clutter. Neon borders, glowing text-shadows, scanlines, and competing pulsating badges produce visual fatigue. |
| 9 | Error Recovery | 2 | Empty catalog search has helpful recovery tips; but crate unlock failure throws a raw browser alert() with no path to replenish XP. |
| 10 | Help and Documentation | 2 | Helpful demo banners and tooltips; lacks FAQs, physical shipping terms, return policies, or key redemption guides. |

## Design Specificity Verdict
Split personality: Bespoke experiential engines (Battlestation Builder, CyberFuel Lab, Loot Crate Roulette) wrapped in category-interchangeable cyberpunk tropes (pitch-black canvas, crimson neon, cut corners, pseudo-military jargon).

## Priority Issues
- [P0] Uncontrollable Audio & Unconstrained Motion (A11y & Sensory Hazard)
- [P1] Crushing Visual Noise Floor & Neon Glow Overload
- [P2] Jargon Barrier & Working Memory Exceeded in Navigation
- [P3] Disruptive Native Browser Alert for XP Gating

## Persona Red Flags
- Alex (Power User): Unskippable 5.5s roulette animation, missing keyboard focus ring indicators.
- Jordan (First-Timer): Overwhelmed by jargon and 12+ competing buttons; startled by unexpected synthesizer audio.
- Sam (A11y-Dependent): No audio mute control, infinite CSS animations ignore prefers-reduced-motion, low-contrast text with glowing halos.
